# crypt_lab_1

## 1. Реализованные алгоритмы

- **Потоковый XOR** — на базе генератора псевдослучайных чисел `Xorshift32`.
- **AES** — симметричный блочный шифр (ключ 128 бит) в режиме ECB и CTR.

---

## 2. Зависимости

Для запуска проекта необходим установленный Python (версии 3.8 и выше) и следующие библиотеки:

* `cryptography` — для реализации блочных шифров AES.
* `numpy` — для матричных вычислений и статистического анализа.
* `Pillow` (PIL) — для работы с изображениями.
* `matplotlib` — для построения и сохранения гистограмм.

Установить зависимости можно одной командой через терминал:
```bash
pip install cryptography numpy pillow matplotlib
```

---
## 3. Команды запуска и параметры

Главный скрипт проекта расположен в папке  `src/`. Запуск осуществляется из корневого каталога проекта `CryptoPic/`.

Основная команда запуска
```bash
python src/main.py "имя изображения в папке imgs".png
```

Параметры:

* Если аргумент не указан, по умолчанию используется `checkerboard.png`.
* Исходное изображение должно находиться в папке `imgs/` и иметь размер не менее 256×256 пикселей.

---

## 4. Пример шифрования/дешифрования

При запуске программа автоматически шифрует выбранное изображение, затем расшифровывает его и проверяет совпадение исходных и восстановленных данных.

Что создается после выполнения:

* results/metrics.csv — сводная таблица со всеми числовыми метриками.
* results/histograms.png — общий файл со сравнительными гистограммами распределения байт.
* results/meta.json — файл метаданных с параметрами алгоритмов.
* В папке imgs/ автоматически сохраняются:
* * Зашифрованные версии файлов (enc_xor_"имя файла".png, enc_ctr_"имя файла".png, enc_ecb_"имя файла".png)
* * Расшифрованные версии файлов (dec_xor_"имя файла".png, dec_ctr_"имя файла".png, dec_ecb_"имя файла".png,) для визуального подтверждения успешного восстановления.

Проверка обратимости и работы алгоритмов:

Процесс расшифрования встроен в основной цикл программы. Для каждого метода автоматически выполняются шифрование и обратное восстановление с контролем целостности через хэши SHA-256.

При успешном запуске в консоли выводится подтверждение:

```bash
Проверка обратимости:
    - Потоковый XOR : СОВПАДАЕТ
    - AES-ECB       : СОВПАДАЕТ
    - AES-CTR       : СОВПАДАЕТ
```
